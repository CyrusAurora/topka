# Documentation

## Use Topka

- [Tutorial](tutorial.en.md) ([简体中文](tutorial.md)): from a fresh clone to cards on screen in about 30 minutes, no API key.
- [Online demo](online-demo.md): what the demo at cyrusaurora.github.io/topka shows and how to publish your own.
- [Self-hosting](self-hosting.md): Docker Compose, models and BYOK, HTTPS, upgrades, backups, troubleshooting.
- [Configuration](configuration.md): every setting.
- [Sources](sources.md): the six source kinds, filters, caps, the push endpoint.
- [Adapt it to another industry](customize.md): the `industry/` pack, step by step.
- [Selection](selection.md): the editorial rubric and how to recalibrate it.
- [Alerts](alerts.md): the webhook that tells you when collection or the budget breaks.
- [Plugins](plugins.md): extra code on a running site via `TOPKA_PLUGINS`.
