# Support

- **Questions and bugs**: [issues](https://github.com/CyrusAurora/topka/issues). Search the existing
  ones first, closed included. For a setup problem, include the exact command and the full error.
- **Security problems**: not in a public issue; see [SECURITY.md](SECURITY.md).
- **Docs**: `docs/` is the reference. A wrong or missing step is a bug; open an issue.

Support is best effort, with no SLA. Confirmed bugs are fixed on `main` and ship in the next release;
security fixes sooner.
