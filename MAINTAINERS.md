# Maintainers

| Area | Maintainer |
| --- | --- |
| Everything (see note) | Cyrus ([@CyrusAurora](https://github.com/CyrusAurora)) |

The project currently has a single maintainer. That is stated plainly rather than hidden: it is
also the honest answer to "what happens if they stop?" — the code is MIT, the docs are complete
enough to run without them, and `SUPPORT.md` says what support actually exists.

Areas where a second maintainer would help most, in order: the web app (`apps/web`), the ingest and
selection pipeline (`packages/backend/src/sources`, `.../publication`), and documentation.

How someone joins is in `GOVERNANCE.md`. Access rights are mirrored in `.github/CODEOWNERS`, and both
change in the same pull request.
